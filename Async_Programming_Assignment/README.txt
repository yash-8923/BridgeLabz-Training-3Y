ASSIGNMENT 6 - ASYNC PROGRAMMING WITH JAVASCRIPT

Folder structure:
- q1 through q10: one folder for each question
- Each folder contains index.html and script.js

How to run:
1. Extract this ZIP file.
2. Open a question folder.
3. Open index.html in a browser.
4. For console-based questions, press F12 and open the Console tab.
5. Q6 fetches product data from the Fake Store API and requires an internet connection.

Notes:
- Each question has its own separate JavaScript file.
- Core JavaScript (ES6+) is used; no frameworks are required.
- Random failures are intentional in questions that ask for failure handling.
