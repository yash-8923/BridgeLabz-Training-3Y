OOP Assignment Submission

Structure:
- q1 to q9: one folder for each question
- Each question folder contains:
  - index.html
  - script.js

How to run:
1. Extract the ZIP file.
2. Open the required q1, q2, ... q9 folder.
3. Double-click index.html to open it in a browser.
4. The JavaScript output will appear on the page.

No external libraries or installation are required.
